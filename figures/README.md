# Paper figures

Current manuscript exports for the November 2026, 191-acquisition all-free fit:

- [Figure 1](figure1.png): study area, fitted mean elevation, REMA and ICESat-2 comparisons.
- [Figure 2](figure2.png): SWOT and CATS tidal amplitudes, differences and western detail.
- [Figure 3](figure3.png): northern transect, observed elevations and two-date residuals.

Figure 3 retains the original observation normalization. The mean absolute
residual difference over the same 214 positions is 32.9 cm for CATS and
24.6 cm for SWOT. This is an in-sample comparison.

These are the manuscript PNGs. To render the figures from completed processing
products, run `python Code/06_make_figures.py` as described in
[the workflow](../Code/README.md). The Python renderers use the paper panel
arrangements; typesetting can differ from these saved exports.
